# Smart-Room-Control-CPP
A C++ simulation for a smart room lighting system using sensor logic.
Smart Room Control (C++)
This project is a Hardware-Software simulation that demonstrates how embedded systems interact with environment sensors.
Key Features:
Logic Control: Automatically toggles light based on ambient brightness levels.
Clean Code: Uses Object-Oriented Programming (OOP) in C++.
Future-Ready: Designed to be easily ported to Microcontrollers (like Arduino or ESP32).
